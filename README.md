# FNaF: FREE ROAM (Fan Game)

بازی سه‌بعدی فناف با قابلیت گشت‌آزادی (free roam) — HTML/JavaScript/Three.js

## اجرا
فایل `fnaf-freeroam.html` را در مرورگر باز کنید (نیاز به اینترنت برای لود مدل‌ها).

## کنترل‌ها
- WASD حرکت · ماوس نگاه · Shift دویدن
- کلیک چپ / F: چراغ‌قوه
- Tab یا C: مانیتور دوربین‌ها

## مدل‌های سه‌بعدی
مدل‌های GLB واقعی از Khronos glTF-Sample-Assets (CC0):
- fox.glb — Freddy (3 انیمیشن: Survey/Walk/Run)
- robot.glb — Bonnie (ریگ کامل)
- brainstem.glb — Chica (انیمیت)
- cesiumman.glb — Foxy (اسکلت متحرک)

## مکانیک‌ها
- سیستم AI شانس‌محور مثل FNaF 1 (هر چند ثانیه roll d20 ≤ AI → جابه‌جایی بین اتاق‌ها)
- چراغ‌قوه با باتری؛ نور مستقیم انیماترونیک را عقب می‌راند
- مانیتور دوربین مداربسته (تعقیب هنگام مشاهده متوقف می‌شود)
- بقا از ۱۲ شب تا ۶ صبح؛ هر ساعت سطح AI +۱
